description: Overview of open Pincushion feedback with a suggested priority order
---

Use the pincushion MCP tool `get_feedback_summary` to get a high-level overview of all feedback across the project.

Present the summary clearly:
- Total open pins, broken down by status (open / claimed / in-review)
- Which pages or URLs have the most unresolved feedback
- Any pins that have been open for more than 3 days (flag as stale)
- Pins that have active thread discussion but no agent response yet

End with a suggested priority order: which pin should be tackled first, and why (e.g. blocking a stakeholder, most comments, oldest open).
